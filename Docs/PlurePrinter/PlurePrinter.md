# PlurE Printer Installation and Configuration Guide

## Description
This guide provides detailed instructions for installing the PlurE Printer desktop application, performing initial setup, and adding new printers. Follow the steps outlined to ensure successful installation and configuration of your printing services.

## Initial Setup and Adding New Printers

1. **Access the administration portal**:  
   - Open your browser and go to: [https://admincenter.plur-e.com/](https://admincenter.plur-e.com/).

2. **Create a new printer**:  
   - In the main menu of the Admincenter PlurE portal, select "Printers".

![image](https://github.com/user-attachments/assets/67dfd0c4-6bd8-4678-851f-9226821f7ee8)

   - Click on the "Create" option.

![image](https://github.com/user-attachments/assets/2836ab57-a466-4228-8941-865c1a3e52fc)

3. **Fill in the required fields**:

![image](https://github.com/user-attachments/assets/91a57224-f542-49ca-9316-b72f23cf78a3)

   - **Name**: Enter the exact name of the printer as it appears in your computer's settings under the devices section.  
   - **Description**: Add a description of the printer.  
   - **Format Printer**: Select the type of printer.  

![image](https://github.com/user-attachments/assets/a3d1ceb2-bc8a-48c9-bd09-422c3d5c6607)

   *Note*: This setup is for local printers. If you need to configure a remote printer, please use the contact form to receive specific instructions.

5. **Save and activate**:  
   - Save the changes made.

6. **Retrieve the printer key**:  
   - Copy the "Printer Key" displayed in the printer list within the PlurE web portal.

![image](https://github.com/user-attachments/assets/e94ff657-d15f-4e80-b18f-554575afb654)

7. **Configure the printer key**:  
   - Paste the copied "Printer Key" into the corresponding field in the application.

![image](https://github.com/user-attachments/assets/656a181a-158d-4fbe-a98a-edcff46aea24)

   - Save the changes and activate the printing service.  

![image](https://github.com/user-attachments/assets/42a207d3-beeb-4226-be6c-0d6a307bee7b)

Your printer will be ready to use.

![image](https://github.com/user-attachments/assets/8a36c17e-4f13-4dea-8708-8b6c93e51b74)
