# LICENSE PLATE RECEIVING MANUAL

## 1. INTRODUCTION

* This manual outlines the procedure for receiving inventory using the License Plate (LP) functionality in the Warehouse module.
* The LP process allows for efficient management and tracking of received items.

## 2. RECEIVING WORKFLOW

### Access Receiving

1. Open the Warehouse module
2. Select the "Receive" option

### Create New License Plate

1. Within the receiving document, choose the "New LP" option

![image](https://github.com/user-attachments/assets/ea8897cc-7836-4e67-9a1c-6ed041155636)

2. This will open a new License Plate record

![image](https://github.com/user-attachments/assets/30990321-3d15-41cc-a471-b714376311fe)

### Scanning and Entering Items

1. Scan the UPC barcode of the item

![image](https://github.com/user-attachments/assets/025e82ef-8b60-4084-83ee-fbdb5f2de5e2)

2. Enter the quantity to be received for that item

![image](https://github.com/user-attachments/assets/b89a46f8-40dc-4d62-b19b-5510745cc59b)

3. If the item is serialized, also scan the individual serial numbers

![image](https://github.com/user-attachments/assets/131a64d8-09e7-4e01-b235-834867e02187)

![image](https://github.com/user-attachments/assets/3102c1d6-45d2-413c-a22a-4c3f31e7db89)

![image](https://github.com/user-attachments/assets/84b3cc69-79a3-434b-844b-b104f45fd275)

### Saving the License Plate

1. After adding all required items, select "Save" to complete the LP

![image](https://github.com/user-attachments/assets/ff78c82f-f80a-4703-8729-af01f56c5b65)

### Reviewing License Plates

1. Use the "List LP" option to view all created License Plates

![image](https://github.com/user-attachments/assets/461fadc7-bb12-4d56-aec0-0d4148ba64f9)

2. Within each LP, you can remove items if needed

![image](https://github.com/user-attachments/assets/e2694adc-58dc-4ec6-ad30-9fc06b0d2c41)

![image](https://github.com/user-attachments/assets/903fa74a-6f34-4fb4-9be5-00cf4e44ef60)

### Posting the Receipt

1. Once all LPs have been created, proceed to post the full Receive document.

![image](https://github.com/user-attachments/assets/8743eb35-a47f-4542-87b3-bfe724e18d18)

![image](https://github.com/user-attachments/assets/eaecce33-b490-40d0-bddf-6086d1f4fb35)
