# **Chat Bot Assistant**

The Chat Bot Assistant is an integrated chatbot within Business Central, connected to OpenAI, designed to:
- Help you understand processes managed by Plur-e.
- Serve as a customized chatbot tailored to the given context.


## **Accessing the Chat Bot Assistant**
- Search for **Chat Bot Assistant** in the Business Central search bar to access it.

![image](https://github.com/user-attachments/assets/c6419b4e-2d96-4b3a-8cd6-ce310514f0f8)

- Alternatively, navigate to the chatbot through the **Plur-e OpenAI Setup** page.

![image](https://github.com/user-attachments/assets/303e8435-ceb0-4b4e-b87f-5b7692250e23)


## **Using the Chat Bot**
Once accessed, you can start chatting directly with the Chat Bot Assistant.

## **Manage Documents**

The Chat Bot's intelligence depends on the documentation it has access to. Manage these documents through the **Manage Documents** section.

![image](https://github.com/user-attachments/assets/a57fdeeb-f7d1-4cca-b3ed-245ae22eda40)

### **Uploading Documents**
1. Navigate to the **Manage Documents** button.
2. Go to the **Actions** section and select **Import Document**.
3. Import the document into the chatbot's database.

![image](https://github.com/user-attachments/assets/f603df78-0d1b-4154-a467-ae0c5745d92c)

![image](https://github.com/user-attachments/assets/c9d56193-1c30-4d3e-ab6b-7db88e66989b)

#### **Specify Document Type**
- After importing, specify the document type.
- The system will ask if the document has a source URL for reference:
  - If it does, click **Yes** and attach the URL.
  - If not, the document will be imported without a source.

![image](https://github.com/user-attachments/assets/bda939e9-36a4-437f-9e0e-768a27d5fcaa)

![image](https://github.com/user-attachments/assets/4481b66f-fd8c-46fd-904e-3eae78932d4e)

![image](https://github.com/user-attachments/assets/a7852dd6-a803-4550-836a-9904c8c1590c)

### **Additional Document Management Options**
From this section, you can:
- **Delete** imported documents.
- View or edit documents as needed.
